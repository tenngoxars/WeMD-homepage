01 /本地优先

你的文字，握在手里

文章只保存在你的电脑里，可以存在浏览器，也可以存进你选的本地文件夹。不用注册登录，也不经过 WeMD 的服务器。

02 /精准预览

复制之前，先看手机里的样子

内置深色模式预览算法，参考微信官方开源实现，在按下复制键前就能看到文章在微信深色模式下的效果，接近实机表现。

03 /主题定制

全能主题编辑器

内置可视化与 CSS 双模式。你可以通过图形界面快速调整，也可以直接编写 CSS 实现任意排版效果。

04 /开源多端

全平台支持

提供 macOS、Windows、Linux 客户端与网页版；网页版支持 PWA，可安装到桌面或主屏并离线使用。作为开源项目，代码完全透明，并支持私有化部署。

05 /AI 辅助

改写、审阅、起标题

选中一段文字即可润色、精简或换语气，也能审阅全文、生成标题。填入自己的 API Key 使用，内容直接发给你选的服务商，不经过 WeMD。
