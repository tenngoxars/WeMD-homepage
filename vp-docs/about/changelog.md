## v1.4.0 (2026-07-27)

### 修复

- 修复部分弹窗关闭后焦点未正确恢复，以及错误页反馈计时器未清理的问题。

## v1.3.0 (2026-07-14)

### 新功能

- **编辑器与预览双向同步滚动**：根据 Markdown 源码位置同步编辑区和预览区，长文章、图片和异步内容较多时也能更准确地保持阅读位置。
- **可调节分栏宽度**：桌面端支持拖动编辑器与预览区之间的分隔线，并会记住上次使用的宽度。
- **Markdown 局部属性**：图片、链接、标题、段落、表格及常用行内格式支持设置 `class`、`id` 和 `data-*` 属性，方便高级排版与自定义主题精确控制局部样式。
- **五套全新内置主题**：新增「编辑部手记」「数据蓝图」「东方笺谱」「清晰指南」「留白画册」，覆盖内刊、数据报告、东方美学、教程和画册等写作场景。
- **表格自动换行开关**：可按发布需要在横向滚动与自动换行之间切换，预览和复制到公众号保持一致。

### 优化

- **内置主题阵容更新**：下架五套较旧的内置主题，减少风格重复；使用旧主题的历史文章仍可正常恢复和渲染。
- **代码块深色主题更清晰**：统一新主题的深色语法高亮，提升代码文字与背景的对比度。
- **复杂公式复制更快更稳定**：优化多公式并行处理、远程图片校验与 SVG/PNG 降级链路，改善复杂公式在公众号中的清晰度、尺寸和暗色背景表现。

### 修复

- 修复代码块复制到微信公众号后多行内容可能合并为一行的问题。
- 修复 Mac 风格代码栏在预览加载时短暂出现白块，以及复制后圆点被公众号清理的问题。
- 修复 Mermaid 图表中较长中文节点文字复制为图片后挤压、重叠的问题。
- 修复同步滚动过程中异步布局变化或主动滚动状态切换导致的位置跳动问题。

## v1.2.11 (2026-06-24)

### 优化

- **文章文件名更贴近标题**：在文件系统模式下，新建文章会优先使用文章标题作为文件名，减少后续手动重命名。
- **浏览器文件夹模式自动刷新**：使用浏览器打开本地文件夹时，页面重新聚焦或从后台回到前台后会自动刷新文件列表，更容易发现外部修改。
- **本地文件管理体验优化**：重命名文章时会同步更新实际 Markdown 文件名，侧边栏与本地文件系统保持一致。
- **桌面端稳定性提升**：重构 Electron 主进程，拆分窗口、菜单、文件、文件夹、剪贴板和更新等处理逻辑，降低后续维护风险。
- **工作区监听增强**：桌面端现在会递归监听工作区目录，子文件夹内新增、删除或修改 Markdown 文件时也能更及时同步。

### 修复

- **Mermaid 复制到公众号更稳定**：修复 Mermaid 图表复制到微信公众号后文本丢失、标题错位或渲染异常的问题。
- **数学公式复制兼容性提升**：优化公式复制到微信公众号的处理链路，减少 `\boldsymbol` 等公式源码暴露、复杂公式丢失或样式退化的问题。
- **表格字号跟随主题**：修复表格复制到微信公众号时字号被固定为 13px 的问题，现在会跟随全局字号与自定义主题设置。
