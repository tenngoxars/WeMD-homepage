# 快速上手

本文档将引导你在 5 分钟内完成从「打开 WeMD」到「发布一篇排版优雅的公众号文章」的全过程。

## 目标
- 使用 WeMD 编写一篇 Markdown 文章
- 完成排版并复制到微信公众号

## 步骤 1：开始写作

### Web 网页版
1. 打开 [WeMD 网页版](https://edit.wemd.app)。
2. 页面会直接显示编辑器，默认使用**浏览器存储模式**。

#### 关于存储模式
Web 版提供两种存储模式，点击顶部导航栏的 **「存储模式」** 按钮可切换：

| 模式 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **浏览器存储** | 文章保存在浏览器内部 (IndexedDB)，关闭网页后文章依然存在 | 临时写作、不想授权文件夹 |
| **本地存储** | 直接读写指定文件夹中的 `.md` 文件，体验接近桌面版 | 长期使用、需要与其他应用共享文件 |

> ⚠️ **注意**：
> - **浏览器存储**：只有在「清除浏览数据」中勾选「Cookie 及其他网站数据」并清除时才会删除文章。
> - **本地存储**：需要浏览器支持 File System Access API。

#### 关于 PWA（安装与离线）

WeMD 网页版支持 PWA，无需安装桌面客户端也能获得类似桌面应用的体验：

- 在 Chrome / Edge 地址栏右侧点击**安装图标**（或菜单 → 安装 WeMD），可安装到桌面（macOS 会装入「应用程序 → Chrome Apps」）或手机主屏。
- 安装后支持**离线打开与写作**：首次加载完成后，编辑器、预览、字体与公式渲染等静态资源都会缓存在本地，无网络时依然可以继续写作；图床上传、复制到公众号等依赖网络的能力除外。

> ⚠️ PWA 安装后的图标与浏览器标签页图标可能因缓存延迟更新，如需强制刷新可清除该站点缓存后重新安装。

**本地存储模式浏览器兼容性**：

| 浏览器 | 支持情况 |
| :--- | :--- |
| Chrome / Edge | ✅ 原生支持 |
| Safari | ❌ 不支持 |
| Firefox | ⚠️ 需手动开启（见下方） |

<details>
<summary>🦊 Firefox 开启方法</summary>

1. 地址栏输入 `about:config`，回车。
2. 点击「接受风险并继续」。
3. 搜索 `dom.fs.enabled`，双击将其设为 `true`。
4. 重启 Firefox。

*注：此为实验性功能，可能不稳定。*
</details>

<details>
<summary>🌐 第三方 Chromium 浏览器（如 Arc、Brave 等）</summary>

部分基于 Chromium 的浏览器可能默认禁用此 API：

1. 地址栏输入 `chrome://flags`，回车。
2. 搜索 `File System Access API`。
3. 将其设为 `Enabled`。
4. 点击「Relaunch」重启浏览器。

</details>

### Desktop 桌面版
1. 前往 [Releases](https://github.com/tenngoxars/WeMD/releases) 下载桌面版安装包。
2. 按系统选择对应文件：macOS 下载 `WeMD-<版本号>-arm64-mac.zip`，Windows 下载 `WeMD.Setup.<版本号>.exe`，Linux 下载 `WeMD-<版本号>.AppImage`。
3. 打开 WeMD 桌面应用。
4. 首次打开会看到欢迎页面，点击 **「选择工作区文件夹」** 按钮。
5. 在系统文件选择器中选择文件夹，无需额外授权。

> 当前自动发布的 macOS 安装包为 Apple Silicon 版本；Intel Mac 可优先使用 Web 网页版或自行从源码构建。

### Docker 部署

如需在自己的服务器上部署 WeMD：

```bash
# 克隆项目
git clone https://github.com/tenngoxars/WeMD.git
cd WeMD

# 拉取镜像并启动
docker compose pull
docker compose up -d
```

启动后在浏览器访问 `http://服务器IP:8080`。

> 浏览器只在 HTTPS 或 `localhost` 下开放读写本地文件夹的能力。通过 `http://服务器IP:8080` 访问时，「本地存储」模式不可用，只能使用浏览器存储。需要本地存储时，可以用 `http://localhost:8080` 访问本机部署的 WeMD，或为服务器配置 HTTPS。

默认会拉取 `ghcr.io/tenngoxars/wemd-web:latest`。  
如需指定版本镜像，可按需替换版本号后再执行：

```bash
WEMD_IMAGE=ghcr.io/tenngoxars/wemd-web:<版本号> docker compose up -d
```

## 步骤 2：创建文档

1. 点击左侧的 **「新建文章」** 按钮。
2. 在编辑器中输入以下 Markdown 内容：

```markdown
# 这是一个标题
这里是一段正文。WeMD 让排版变得**如此简单**。
```

## 步骤 3：排版与预览

1. 看向右侧的 **预览区**。你会发现刚才输入的文字已经自动变成了公众号的样式。
2. 点击顶部导航栏的 **「文章主题」** 按钮。
3. 在弹出的面板中，选择 **「内置主题」** 列表中的任意主题，如「学术论文」或「落日胶片」。
4. 预览区会实时更新样式。

## 步骤 4：发布

1. 点击顶部导航栏的 **「复制到公众号」** 按钮。
2. 打开微信公众号后台编辑器。
3. 按下 `Cmd+V`（Windows 为 `Ctrl+V`）粘贴。

你已经用 WeMD 完成了第一篇排版好的文章。

## Web 与 Desktop 功能差异

| 功能 | Web 网页版 | Desktop 桌面版 |
| :--- | :--- | :--- |
| 默认存储 | 浏览器内 (IndexedDB) | 本地文件夹 |
| 存储模式切换 | ✅ 顶部「存储模式」按钮可切换 | ❌ 无，固定使用本地文件夹 |
| 文件变更刷新 | 回到页面或重新聚焦时刷新本地文件列表 | 递归监听工作区，外部修改自动刷新 |

## 进阶技巧

- **一键格式化**：点击编辑器工具栏的「格式化」按钮，可以一键在中英文之间加空格、把标点转成全角、引号转成直角引号「」，并清理零宽字符、行尾空格和多余空行。每条规则都能单独开关，代码、公式、链接和 HTML 不会被改动，格式化后可以撤销。
- **导出**：顶部导航栏的「导出」菜单里有「复制 HTML」和「导出长图」。复制 HTML 可以把排版结果用在其他编辑器；导出长图会按手机宽度生成 PNG 图片。
- **AI 写作辅助**：配置 API Key 后，可以改写选中的文字、审阅全文和起标题，详见 [AI 写作辅助](/guides/ai-writing)。
- **深色模式预览**：点击顶部导航栏的月亮图标，可预览文章在微信深色模式下的效果。
- **外链转脚注**：在编辑器工具栏中开启「外链转脚注」，文章中的链接会自动转为文末脚注。
- **语法参考**：查看 [Markdown 语法参考](/reference/markdown-syntax) 了解所有支持的扩展语法。
- **快捷键**：查看 [快捷键列表](/reference/hotkeys) 提升编辑效率。
