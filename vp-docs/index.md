# WeMD 文档

欢迎来到 WeMD 文档中心。

WeMD 是一款专为微信公众号设计的 Markdown 编辑器，支持一键复制到公众号、多款文章主题、深色模式预览和 AI 写作辅助等功能。

## 核心功能

| 功能 | 说明 |
|------|------|
| **复制到公众号** | 针对微信公众号粘贴适配，尽量保持预览效果 |
| **导出** | 复制排版后的 HTML，或按手机宽度导出 PNG 长图 |
| **多主题** | 内置多款文章主题，可继续自定义 CSS 或使用可视化设计器 |
| **深色模式预览** | 预览微信深色模式效果 |
| **一键格式化** | 中英文加空格、标点转全角、引号转直角引号、清理多余空白，规则可开关 |
| **AI 写作辅助** | 选区改写、全文审阅和起标题，使用自己的 API Key，详见 [AI 写作辅助](/guides/ai-writing) |
| **本地优先** | 数据存储在本地，无需登录 |
| **PWA 安装** | 可安装到桌面/主屏，支持离线写作 |

## 技术亮点

WeMD 内置了 [微信深色模式预览算法](/reference/dark-mode-algorithm)，发布前就能在编辑器里预览文章在微信深色模式下的效果，接近实机表现。
