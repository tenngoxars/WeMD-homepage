# AI 写作辅助

WeMD 提供三项 AI 写作辅助：**选区改写**、**全文审阅**和**起标题**。使用前需要填入你自己的 API Key，请求从浏览器直接发到你选择的服务商，不经过 WeMD 的服务器。

## 配置服务商

1. 点击顶部导航栏的 **「AI 优化」**。
2. 在 **「服务商」** 中选择一家。支持 DeepSeek、Kimi、通义千问、硅基流动、模力方舟、OpenAI、OpenRouter，以及自定义的 OpenAI 兼容服务。
3. 填入 **API Key**。输入框下方有「获取 xx API Key」链接，可以直接打开对应服务商的密钥页面。
4. **模型**会预填一个默认值。点击输入框右侧的箭头可以拉取服务商的模型列表，也可以直接手动填写模型名。
5. 点击 **「测试连接」**。连接成功后，配置会自动保存并启用 AI 优化。

> 每家服务商的 Key 和模型分开保存，切换服务商不会把上一家的 Key 带过去。Key 只保存在本机，不会上传到 WeMD。

**自定义服务**：选择「自定义」后需要额外填写 Base URL，例如 `https://your-endpoint/v1`。接口需要兼容 OpenAI 的 `/chat/completions`，并且允许浏览器跨域调用（CORS）。

**写作偏好**：可以写下长期适用的要求，例如「读者是产品经理；不要口语化」，最多 200 字。写作偏好会用在改写、全文审阅和起标题三项中，留空则不发送。

关闭「启用 AI 优化」开关后配置会保留，选区旁不再出现改写按钮，工具栏的全文审阅和起标题按钮变为不可用。

## 选区改写

在编辑器中选中一段文字，选区旁会出现 **「改写」** 按钮，点击后可以选择：

| 动作 | 说明 |
| :--- | :--- |
| 润色 | 让表达更通顺 |
| 精简 | 删掉冗余，保留原意 |
| 口语化 | 改成更自然的说法 |
| 换语气 | 可选专业、轻松、亲切、犀利 |
| 自定义要求 | 在输入框里写下要求，最多 200 字 |

结果会逐步生成。生成后可以替换原文、重试或取消，替换后按撤销可以恢复。选区需要在 4 到 4000 字之间。

## 全文审阅

点击编辑器工具栏的 **「全文审阅」** 按钮，AI 会从开头、结构、节奏、表达和结尾五个方面审阅整篇文章。指出的问题会引用原文，点击可以定位到对应位置；能直接执行的修改建议可以一键采纳，采纳后也能撤销。

## 起标题

点击编辑器工具栏的 **「起标题」** 按钮，AI 会按直给、疑问、数字、反差、场景五个方向生成标题候选，并标出推荐项。每个候选会显示字数，公众号标题上限为 64 字。选定后可以直接写入文章标题。

## 会发送哪些内容

| 功能 | 发送内容 |
| :--- | :--- |
| 选区改写 | 选中的片段，以及它前后各一段作为上下文 |
| 全文审阅、起标题 | 正文前 12,000 字，超出时会明确提示 |

写作偏好会随每次请求一起发送。除此之外，WeMD 不会把文章发给任何服务商。

## 常见问题

### 提示「API Key 无效或没有权限」

Key 填错、已过期或被删除时会出现这个提示。请到服务商的控制台重新复制 Key，注意不要带上首尾空格。

### 提示「请求过于频繁或额度不足」

服务商限制了请求频率，或者账户余额不足。稍后再试，并检查服务商账户的余额。

### 提示「请求被拒绝」，通常是模型名不正确

请确认模型名和服务商提供的完全一致，包括大小写。可以点击模型输入框右侧的箭头，从列表中选择。

### 测试连接成功，但提示首字很慢

测试连接会记录第一个字返回的时间。超过 8 秒时，实际使用会明显卡顿，建议换一个更快的模型或服务商。

### 自定义服务连不上

先确认 Base URL 填写正确。如果地址没问题仍然连不上，通常是该接口没有允许浏览器跨域调用（CORS），需要在服务端开启。

### 模型列表拉取失败

不是所有兼容服务都提供模型列表。拉取失败时可以直接手动填写模型名，不影响使用。
